# 蒋华健 - 中文个人网站

一个参考 guoxuxu.github.io 视觉风格制作的中文静态个人网站，展示应用人工智能工程、研究、项目和工作经历。网站使用原生 HTML、CSS 和 JavaScript，不需要构建步骤，也不依赖第三方运行时。

## Preview

可以直接打开 `index.html`，也可以在当前目录启动本地服务器：

```bash
python3 -m http.server 4173
```

然后访问 `http://127.0.0.1:4173`。

## Files

- `index.html` - 个人简介、项目、研究、工作经历、教育背景、技能和联系方式
- `styles.css` - 响应式布局和视觉样式
- `script.js` - 本地 Canvas 项目示意图
- `assets/profile-photo.jpg` - 网站所有者提供的个人照片
- `assets/quant-platform.jpg` - 量化平台界面截图
